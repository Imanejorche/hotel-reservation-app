# HotKech - Hotel Reservation Web Application

HotKech is a web application developed with PHP and Laravel for hotel reservation management. The application provides features for managing rooms, reservations, user accounts, and comments through an MVC-based architecture.

## Features

- Room management
- Reservation management
- User account management
- Comment management
- Database-driven web application

## Technologies

- PHP
- Laravel
- MySQL
- Blade
- HTML
- CSS
- JavaScript
- MVC architecture

## Project Structure

- `app/`: application logic, models, and controllers
- `routes/`: application routes
- `resources/`: Blade views and front-end resources
- `database/`: migrations and database files
- `public/`: public assets
- `config/`: application configuration
- `composer.json`: PHP dependencies and project configuration
